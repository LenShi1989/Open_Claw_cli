# MCP 工具表

| **Chrome DevTools MCP** | Chrome Debug、Network、Console、Performance | `npx chrome-devtools-mcp@latest`                       |   ✅    |   ⭐⭐⭐⭐ |
| **Filesystem MCP**      | 讀寫指定目錄、搜尋檔案                      | `npx @modelcontextprotocol/server-filesystem`          |   ✅    | ⭐⭐⭐⭐⭐ |

| **Docker MCP**          | Docker 容器/映像相關操作                    | Docker MCP Toolkit                                     |   ✅    | ⭐⭐⭐⭐⭐ |
| **Fetch MCP**           | HTTP 網頁/文件抓取                          | Python / Node                                          |   ✅    |   ⭐⭐⭐⭐ |
| **Brave Search MCP**    | Web 搜尋                                    | API + MCP                                              |   ✅    |   ⭐⭐⭐⭐ |
